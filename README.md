# Jade - Obsidian風Markdownエディタ

## 📄 概要

**Jade**は、Obsidianにインスパイアされた高機能Markdownエディタです。ライブプレビュー、双方向リンク、グラフビジュアライゼーション、YAMLフロントマターによるプロパティ管理など、ナレッジベースとして必要な機能を備えています。

### 主な特徴

- ✨ **Obsidian風ライブプレビュー**: CodeMirror 6ベースのリアルタイムMarkdownプレビュー（カーソル行は編集モード、他の行はプレビュー）
- 🔗 **双方向リンク**: `[[ノート名]]`記法によるノート間リンクとグラフビジュアライゼーション
- 🏷️ **YAMLフロントマター**: タグ、ステータス、作成日、更新日などのメタデータ管理
- 📊 **グラフビュー**: D3.jsによる力指向グラフで、Wikiリンクとタグベースの関連性を可視化
- 💾 **自動保存**: 1秒のデバウンスで自動的にノートを保存
- 🔍 **全文検索API**: Elasticsearch検索APIは提供済み（UIは未実装）
- 🎨 **ダークテーマUI**: VS Code風のモダンなインターフェース
- 🐳 **Docker完全対応**: すべてのサービスをDocker Composeで一括管理

## 🏗️ アーキテクチャ

### システム構成

| コンポーネント | 技術スタック | 役割 |
|:---|:---|:---|
| **クライアント (UI)** | React 18 / TypeScript / Vite / CodeMirror 6 | Markdownエディタ、グラフビュー、プロパティ管理 |
| **バックエンド (API)** | Bun / Express / TypeScript | REST API、ノートCRUD、検索インデックス管理 |
| **ストレージ (デフォルト)** | ファイルシステム (`vault/`) | Markdownファイルをローカル保存。`VAULT_PATH` が指定されているためDocker構成でもこのモードで動作 |
| **オブジェクトストレージ (オプション)** | MinIO (S3互換) | 将来のS3互換ストレージ移行用。現在の実装では未使用 |
| **メタデータDB (オプション)** | DynamoDB Local | 将来のメタデータ管理用。現在の実装では未使用 |
| **全文検索エンジン** | Elasticsearch | ノート内容の全文検索インデックス |
| **状態管理** | Zustand | クライアント側のグローバル状態管理 |

## ✨ 実装済み機能

### エディタ機能
- ✅ **ライブプレビューエディタ**: CodeMirror 6カスタムプラグインによる行単位のプレビュー
- ✅ **Wikiリンク記法**: `[[ノート名]]`でノート間リンクを作成
- ✅ **自動保存**: 1秒デバウンスで編集内容を自動保存
- ✅ **タイトル編集**: インライン編集によるノートタイトルの変更
- ✅ **シンタックスハイライト**: Markdown構文の色分け表示

### プロパティ管理
- ✅ **YAMLフロントマター**: `---`で囲まれたメタデータのパース・編集
- ✅ **動的プロパティ**: プロパティの追加・削除が自由に可能
- ✅ **タグ管理**: 複数タグの追加・削除、Enterキーで即座に追加
- ✅ **ステータス管理**: 進行中/完了/保留/アーカイブのドロップダウン選択
- ✅ **日付管理**: 作成日・更新日の自動設定と手動編集
- ✅ **カスタムプロパティ**: 任意のキー・値ペアを自由に追加

### グラフビュー
- ✅ **力指向グラフ**: D3.jsによる動的なノード配置
- ✅ **Wikiリンク表示**: `[[]]`で繋がったノートを青い実線で接続
- ✅ **タグベースリンク**: 同じタグを持つノートを紫の破線で接続
- ✅ **ノードクリック**: グラフ上のノードをクリックして該当ノートを開く
- ✅ **リンク凡例**: リンクの種類を視覚的に区別

### UI/UX
- ✅ **分割画面**: エディタとグラフビューの同時表示
- ✅ **サイドバー折りたたみ**: ノート一覧の表示/非表示切り替え
- ✅ **状態永続化**: 最後に開いたノートとグラフビュー表示状態をlocalStorageで保存
- ✅ **タイムスタンプ自動生成**: 新規ノート作成時に「無題のノート 12月6日 18:06」形式のタイトル
- ✅ **ワンクリック作成**: ダイアログなしで即座にノートを作成

## 🐳 ローカル開発環境

すべてのサービスは**Docker Compose**で一括管理されます。

### 必要な環境
- **Docker** (必須)
- **Docker Compose** (必須)

### Docker構成
- **minio**: S3互換オブジェクトストレージ (ポート: 9000, 9001)
- **dynamodb**: DynamoDB Local インメモリモード (ポート: 8000)
- **elasticsearch**: 全文検索エンジン (ポート: 9200, 9300)
- **api**: バックエンドAPIサーバー（Bun + Express）(ポート: 8080)
- **client**: フロントエンド開発サーバー（Vite）(ポート: 3000)

**補足:** 現行のAPIは `VAULT_PATH=/vault` を指定し、ノートはファイルシステムに保存します。MinIOとDynamoDBはコンテナ起動のみで、データ保存には使用しません。

### セットアップ

```bash
# リポジトリのクローン
git clone https://github.com/u1e2k/markdown-editor.git
cd markdown-editor

# すべてのサービスを一括起動
docker compose up -d

# ログ確認
docker compose logs -f

# サービスの停止
docker compose down
```

### サービスエンドポイント

| サービス | URL | 説明 |
|:---|:---|:---|
| **アプリケーション** | http://localhost:3000 | メインのMarkdownエディタUI |
| **API** | http://localhost:8080 | REST APIエンドポイント |
| **MinIO Console** | http://localhost:9001 | オブジェクトストレージ管理画面 (minioadmin/minioadmin) |
| **Elasticsearch** | http://localhost:9200 | 検索エンジンAPI |

## 📖 使い方

### ノートの作成
1. サイドバーの「+ 新規作成」ボタンをクリック
2. 自動的にタイムスタンプ付きのタイトルが生成される
3. タイトルと本文を編集（自動保存）

### Wikiリンクの作成
```markdown
[[他のノート名]]でリンクを作成
```

### YAMLフロントマターの編集
```yaml
---
tags: [プロジェクト, アイデア]
status: 進行中
created: 2025-12-06
updated: 2025-12-06
custom_field: カスタム値
---

本文はここから
```

### グラフビューの使用
1. サイドバーヘッダーの🔗ボタンをクリック
2. グラフビューとエディタが分割表示される
3. ノードをクリックして該当ノートを開く
4. ノードをドラッグして配置を調整

### プロパティの管理
1. エディタ上部の「プロパティ」パネルを展開
2. タグ入力欄でタグを追加（Enterキー）
3. ステータスをドロップダウンから選択
4. 「+ プロパティを追加」で任意のプロパティを追加
5. 各プロパティの×ボタンで削除

## 🛠️ 技術的決定事項

### エディタ
- **CodeMirror 6**: Monaco Editorから移行（Wikiリンク構文のカスタマイズが容易）
- **カスタムプラグイン**: ライブプレビューをWidgetとDecorationで実装

### 状態管理
- **Zustand**: Reduxより軽量で、TypeScript対応が良好

### データフロー
- **YAML frontmatter**: ノート本文と分離してパース・編集し、保存時に結合
- **自動日付更新**: 編集時に`updated`フィールドを自動更新、`created`は保持

### Elasticsearch統合
- **Bun互換性**: 公式クライアントの代わりにfetch APIベースの簡易クライアント実装

### DynamoDB Local
- **インメモリモード**: ファイルシステム権限問題を回避（データは揮発性）
