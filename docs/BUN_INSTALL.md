# Bun のインストール

Bun がインストールされていない場合は、以下のコマンドでインストールしてください:

## Linux / macOS / WSL

```bash
curl -fsSL https://bun.sh/install | bash
```

## Windows (PowerShell)

```powershell
powershell -c "irm bun.sh/install.ps1 | iex"
```

## バージョン確認

```bash
bun --version
```

## Bun を使用する理由

- ⚡ **高速**: npm/yarn より 10-20 倍高速なパッケージインストール
- 🔋 **オールインワン**: バンドラー、トランスパイラー、パッケージマネージャーを統合
- 🎯 **Node.js互換**: 既存の Node.js プロジェクトと互換性あり
- 📦 **軽量**: インストールサイズが小さい
